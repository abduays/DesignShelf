# DesignShelf for Chrome

This folder contains the Chrome Manifest V3 package.

For the product overview, features, privacy notes and development instructions, see the [main README](../README.md).

## Load locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `chrome/` folder.

This is a development build, not a Chrome Web Store release.
