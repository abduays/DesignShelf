# Third-party project and licence review

This register distinguishes references and research candidates from software or assets included in DesignShelf. It is not a dependency inventory.

| Project | Licence | Current use | Adoption notes |
|---|---|---|---|
| [axe-core](https://github.com/dequelabs/axe-core) | MPL-2.0 | Research candidate only; not bundled | If adopted, pin a release, include notices, review MPL source obligations for modified covered files and test browser isolated worlds. |
| [ProjectVisBug](https://github.com/GoogleChromeLabs/ProjectVisBug) | Apache-2.0 | Interaction-pattern reference only | No code or artwork copied. |
| [Tabster](https://github.com/microsoft/tabster) | Check upstream licence before any future adoption | Keyboard-navigation reference; not adopted | Native semantics and a small controller are used instead. |
| [SmolVLM-Instruct](https://huggingface.co/HuggingFaceTB/SmolVLM-Instruct) | Apache-2.0 model card | Research candidate only | Not downloaded, bundled or called. Review model, code and runtime/dependency licences separately if evaluated later. |

DesignShelf's own code is licensed under the MIT License in the repository's `LICENSE` file. That licence does not grant rights to captured website content, third-party assets, fonts, images, or material users export from websites.

No third-party runtime code is listed as bundled by this register. Recheck exact versions and licence files before future adoption.
