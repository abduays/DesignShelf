# Brand asset direction

The DesignShelf mark uses a simple shelf/spine motif with small oxide-red index tabs. It references the product's core activity: collecting and indexing interface specimens.

- Source vector: `icons/designshelf-mark.svg`
- Browser assets: `icons/icon16.png`, `icons/icon32.png`, `icons/icon48.png`, `icons/icon128.png`
- Palette: ink `#202923`, paper `#FBFAF5`, oxide `#B34631`
- No gradients, external image assets or font dependencies.
